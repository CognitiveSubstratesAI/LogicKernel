# Port inventory

Every kernel file that ports or re-expresses upstream code, as its own header declares it. The table
below is **generated** from those headers by `tools/port_check.jl --write-inventory`, and the suite
fails if it drifts from them — so it cannot go stale by hand-editing.

## The rule (2026-10-02)

LogicKernel MIRRORS swipl-devel (first priority) and scryer-prolog — see `docs/architecture.md`.

* **A ported file lives at upstream's path**: `swipl-devel src/pl-index.c` → `src/pl-index.jl`,
  `boot/tabling.pl` → `boot/tabling.jl`, `tests/core_lang/test_bips.pl` → `test/core_lang/test_bips.jl`,
  `scryer-prolog src/lib/tabling.pl` → `scryer-prolog/src/lib/tabling.jl`. swipl-devel's `bench/` is a
  git SUBMODULE (github.com/SWI-Prolog/bench), recorded as repo `swipl-bench` with its own commits and
  mounted at `bench/` as upstream mounts it: `swipl-bench programs/derive.pl` → `bench/programs/derive.jl`.
* **Its header** names the upstream file and the commit it was READ at, its class, and — for code
  ports — the upstream copyright line(s) verbatim:
  ```julia
  # UPSTREAM: swipl-devel src/pl-prims.c @ bae881a24a3f
  # CLASS: code
  # COPYRIGHT: Copyright (c)  1985-2024, University of Amsterdam
  ```
* **A ported function — or test unit — keeps upstream's name**, marked so a grep for the upstream
  name lands on it:
  ```julia
  # PORT: pl-prims.c compareStandard
  # DIVERGES: <only where every-clause-fires / multiset semantics require a different behaviour>
  ```
  In a test file the marker precedes `@testset "<upstream unit name>"`. `# PORT: <file> <name> as
  <julia-name>` is for names Julia cannot spell as-is (a Prolog `$name`).
* **Everything else** opens with `# ORIGINAL: <why there is no upstream counterpart>`, in the nearest
  SWI area, never shadowing an upstream file.

**Class** decides the method: **code** — the algorithm carries over (tries, variant checking, term
hashing, WFS delays and completion, index assessment, attributed-variable hooks), upstream's tests
come with the port, and `swipl` runs as a live differential; **design** — re-expressed for
every-clause-fires multiset semantics, never transliterated (clause compilation, instructions,
frames, generations, clause GC). Prolog-the-language runtime (modules, streams, threads, FFI,
debugger, ISO built-ins) is not ported.

`tools/upstream_drift.jl` reports, per ported file, the upstream commits since the recorded one and
how many of the upstream file's functions are ported.
