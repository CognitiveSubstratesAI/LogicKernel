# G1-GC safe points: the audit table (piece G1-2)

Owner: G1-GC (stack garbage collection, R2). Pin 18168e62 (10.1.20). This table is the gate for G1-3..G1-6: **a collector may run only at a point
this table rules SAFE**, and the kernel passes `ALLOW_GC` (pl-incl.jl) only at those points. Written by G1-2; the hook it describes is
`considerGC` (src/pl-gc.jl), called from `ensureGlobalSpace(ld, n, flags, site)` (src/pl-alloc.jl) when `flags & ALLOW_GC != 0`.

## What a safe point is

Upstream, `garbageCollect` runs only (pl-gc.c at the pin): (1) `f_ensureStackSpace` when a stack AREA is full, behind `ensureGlobalSpace(n, ALLOW_GC)`,
`ensureStackSpace(g, t)`, `ensureTrailSpace(n)` and `makeMoreStackSpace(rc, ALLOW_GC)` (pl-gc.c:4713, :4646); (2) the signal `SIG_GC` (pl-setup.c:830-833,
raised by `considerGarbageCollect` at the end of an exception, pl-wam.c:1971) at `handleSignals` (pl-vmi.c:1969 depart_alerted, :4768 I_FREDO, :5570,
:6935, and after a resumed exception :5314); (3) `exceptionUnwindGC` (pl-wam.c:1990-1998); (4) `GC_USER`: `garbage_collect/0` (pl-gc.c:4583),
`set_stack_limit` (pl-setup.c:1868), the idle hook (pl-alloc.c:1880); (5) `FAKE_GC` (pl-vmi.c:238-251): a debug macro that collects at every
`ENSURE_*_SPACE`, never used at the pin (the model of `ld.gc_force`).

Upstream collections MOVE cells (compaction) and relocate every root it knows: the term references (`LD->tmp.h`, foreign frames, `PushPtr`), the
frames' arguments and variables, the argument stack, the global variables, the attvar chain, the VM registers saved by `get_vmi_state`. A `Word`
a C function derived from the heap before such a call is stale after it: upstream re-derives it (`onchange`, `deRef2(ARGP, p)`) or roots it
(`PushPtr`/`PopPtr`, `PushVal`). The kernel's positions are indices into `ld.gstack`: a compacting collector moves what they index.

**Verdicts.** SAFE: nothing derived from the heap before the call is used after it (everything is re-read from a `term_t` slot = a root), and no
kernel caller up the chain holds one. SAFE-REGISTERS: a VM instruction whose only held values are the registers (FR, PC, ARGP): safe once the
macro saves them around the hook (it already does `@SAVE_REGISTERS` before raising). NEEDS-ROOT: a position or word is held across the call: it
needs a `PushPtr`/`PopPtr` twin (`ld.tmp_h`/`ld.tmp_top`, `pushWordAsTermRef`) or a re-derive. NEEDS-REFACTOR: the site's shape must change (a
retry loop, `onchange`). NOT-A-SAFE-POINT: never collects upstream either, or cannot arise here (BY DESIGN). NO-COUNTERPART: the kernel has no call
at this place (left to the owner named); the row records the upstream fact for the owner. MACRO: the run loop's macro.

**Preconditions** (every SAFE builtin site shares them; G1-6 provides them, the hook does not): P1 a builtin is reached from the VM through the foreign
call path with its foreign frame open: its arguments are term_t slots (roots) and the VM registers are saved (`@SAVE_REGISTERS`) before the call;
P2 no Julia local of an enclosing frame holds a heap position (the builtins called from Julia helpers, e.g. `PL_recorded`, are API functions: term_t only).
